# 训练大师

[English](README.md) | **简体中文**

训练大师是一款 SDVX 训练模组，提供多种练习功能

> [!NOTE]  
> 支持 EXCEED GEAR FINAL（2025120900），NABLA 及以上

## 下载

前往 Actions 页面下载最新构建版本

## 使用

将 `trainingmaster.dll` 和 `trainingmaster.ini` 放入 contents 根目录或 modules 文件夹，然后使用 spice2x 注入

启动游戏后按 `Insert` 打开界面

## 功能

> [!NOTE]  
> 开启时成绩的记录与上传会被屏蔽

| 功能 | 说明 |
| --- | --- |
| 播放控制 | 定位、暂停、继续或倒放 |
| 播放倍率 | 将速度调整为 0.25x 至 2.00x，并提供预设按钮 |
| 循环 | 标记 IN 和 OUT 点，持续循环或循环一次 |
| 循环缓冲 | 设置选中循环区域前后增加的时间 |
| 谱面预览 | 查看Note和旋钮轨迹，并编辑循环点 |
| 自动演奏 | 启用游戏原生自动演奏：全部、仅按钮或仅旋钮 |
| 谱面流速 | 固定谱面流速 |
| 镜头 | 阻止镜头移动 |
| 隐藏歌曲演出（实验性） | 练习时隐藏额外贴图动画、画面特效和 Live2D；部分效果无法被移除 |
| 血条 | 覆盖血条类型和初始值 |
